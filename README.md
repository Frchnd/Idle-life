# Hidup — Build Z

Fase 5 Expansion berlanjut dengan **World Expansion I**.

## Baru di Build Z
- Save version 22; save Build Y dan versi sebelumnya tetap bermigrasi lewat key lama.
- 2 sektor ekonomi baru: **Hospitality** dan **Logistik**.
- 2 tempat kerja baru: **Kafe Senja** dan **Lintas Kota Logistik**.
- 4 posisi baru: Barista Pemula, Barista Senior, Staf Gudang, Koordinator Pengiriman.
- 2 skill baru: Hospitality dan Logistik; keduanya baru tampil setelah benar-benar ditemukan/dilatih.
- 2 karakter baru: **Sari** (Kafe Senja) dan **Dimas** (Lintas Kota). Hubungan dan progres hidup mereka ikut disimulasikan.
- First-day event untuk dua tempat baru + jalur promosi yang dipengaruhi pengalaman, hubungan, dan kondisi perusahaan.
- Demand Hospitality/Logistik bergerak mingguan dan dapat membuka shift pasar yang diperebutkan.
- Kafe/Logistik punya kesehatan perusahaan, kas, staffing, tekanan kerja, hiring/restrukturisasi, dan kompetitor lokal seperti sektor lama.
- Jalur mandiri sekarang juga dapat tumbuh dari skill Hospitality atau Logistik.
- Asset anime baru dipakai langsung untuk scene, workplace thumbnail, dan portrait Sari/Dimas.
- UI colorful/playful Build X/Y dipertahankan; grid DUNIA disesuaikan agar 5 sektor tetap rapi di HP/desktop.

## Deploy
Upload seluruh isi folder ini ke root GitHub Pages. Jangan hapus localStorage jika ingin meneruskan save lama. Setelah deploy, hard refresh/tutup-buka PWA agar cache `hidup-build-z-v1` aktif.
