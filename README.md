# Hidup — Build P

Build P menutup fokus utama Fase 3 (Simulation Engine) dengan kompetisi pasar lokal yang sistemik.

## Yang baru

- Save Build O dimigrasikan otomatis ke version 12.
- Setiap sektor punya kompetitor lokal yang bergerak mingguan.
- Kompetitor bisa fokus harga, kualitas, ekspansi, atau menjaga posisi.
- Reputasi pasar usaha player dipisahkan dari kualitas operasional internal.
- Posisi pasar dibandingkan secara sistemik terhadap kompetitor.
- Pelanggan bisa dimenangkan atau hilang karena persaingan dan perhatian player.
- Gerakan kompetitor sesekali memicu keputusan contextual, bukan dashboard micromanagement.
- Respons player: kualitas, harga agresif, menjaga pelanggan tetap, atau tetap seimbang.
- NPC berpengalaman dapat memperkuat tekanan sektor secara tidak langsung.
- UI tetap hanya HIDUP / DUNIA / KAMU.

## Deploy

Upload seluruh isi folder ini ke root GitHub Pages, termasuk `src/` dan `styles/`. Setelah deploy, refresh/tutup-buka PWA agar service worker Build P mengganti cache lama.
