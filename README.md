# Hidup — Build AA

## City Life Expansion

Build AA membuat Kota Harapan punya lokasi yang dapat dikunjungi langsung dari tab DUNIA. Lokasi bukan dekorasi: setiap kunjungan menghabiskan waktu dan uang serta memberi konsekuensi pada skill, hubungan, kondisi, dan peluang.

### Lokasi baru
- **Kampus Harapan** — 4 jam · Rp25.000. Belajar, Teknologi, dan hubungan dengan Andi berkembang. Setelah cukup sering datang, bisa muncul proyek acara kampus.
- **Pasar Tradisional** — 3 jam · Rp10.000. Sosial dan Logistik berkembang, mengenal Bu Lestari, dan bisa membuka pekerjaan bantu pedagang.
- **Gym Sehat** — 2 jam · Rp30.000. Pemulihan aktif untuk menurunkan kelelahan tanpa menghabiskan 8 jam seperti istirahat penuh.

### NPC kota
- **Andi** — mahasiswa aktif di komunitas Kampus Harapan.
- **Bu Lestari** — pedagang lama di Pasar Tradisional.

### Save
Build Z (v22) otomatis dimigrasikan ke Build AA (v23). SAVE_KEY lama tetap dipertahankan.

### Deploy
Upload seluruh isi folder ke root GitHub Pages. Setelah deploy, hard refresh atau tutup-buka PWA agar cache `hidup-build-aa-v1` aktif.
