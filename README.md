# Hidup — Build N

Build N melanjutkan Fase 3 (Simulation Engine) dan memperdalam usaha kecil tanpa menambah tab baru.

## Yang baru
- Save version 10, tetap memakai key save lama agar Build F–M ikut termigrasi.
- Usaha kecil punya kapasitas mingguan yang nyata.
- Permintaan bisa melebihi kapasitas dan sebagian pekerjaan bisa terlewat.
- Pelanggan tetap memberi permintaan stabil tetapi membutuhkan perhatian rutin.
- Upgrade peralatan mengubah uang tunai menjadi kapasitas usaha.
- Konflik waktu antara pekerjaan utama dan pelanggan usaha bisa memaksa trade-off.
- Pelanggan tetap dapat pergi jika usaha lama tidak dikelola.
- Pemilik usaha yang sedang tidak punya pekerjaan utama tetap bisa mengurus usaha dan routine offline tidak mengabaikannya.
