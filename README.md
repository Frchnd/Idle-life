# Hidup — Build O

Build O melanjutkan Fase 3 (Simulation Engine) dengan memperdalam transisi dari pekerja mandiri menjadi pemilik usaha kecil yang mulai bergantung pada orang lain.

## Yang baru
- Save version 11, tetap memakai save key lama agar progres Build F–N ikut termigrasi.
- Usaha yang kewalahan dapat merekrut helper pertama bernama Ari.
- Helper menambah kapasitas, tetapi membawa biaya upah mingguan dan risiko margin turun.
- Ari punya trust dan skill yang tumbuh jika player mengelola usaha bersamanya.
- Setelah beberapa minggu, player dapat mulai mendelegasikan pekerjaan rutin.
- Delegasi mengurangi ketergantungan pada kehadiran player, tetapi kualitas dapat bermasalah jika trust/skill helper belum matang.
- Event masalah helper dapat diselesaikan dengan membina Ari atau mengambil kembali kontrol.
- Usaha yang cukup sehat dapat memicu keputusan besar: tetap hybrid dengan pekerjaan utama atau meninggalkan gaji tetap dan fokus penuh sebagai pemilik usaha.
- Fokus penuh menambah kapasitas dan reputasi usaha, tetapi menghilangkan keamanan gaji harian.
- Menutup usaha tidak lagi mengunci jalur usaha selamanya; player dapat membangunnya kembali di masa depan.
- Tetap hanya memakai tab HIDUP / DUNIA / KAMU.
