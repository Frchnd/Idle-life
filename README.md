# HIDUP — Build AF

Build AF menambahkan Personal Finance & Lifestyle tanpa mengubah game menjadi simulator perbankan. Pemain hanya mengatur keputusan yang benar-benar memengaruhi ritme hidup: dana darurat, gaya hidup, dan transportasi.

## Personal Finance & Lifestyle

- Sistem terbuka setelah Raka mulai punya ritme kerja atau sudah pernah pindah rumah.
- Dana darurat terpisah dari uang tunai dan otomatis membantu menutup kekurangan ketika tagihan bulanan datang.
- Target dana darurat mengikuti satu bulan biaya rutin aktual.
- Gaya hidup: Hemat / Seimbang / Nyaman. Biaya lebih tinggi memberi recovery dan ritme harian yang lebih nyaman.
- Transportasi: Angkot & Ojek / Sepeda Bekas / Motor Bekas.
- Sepeda dan motor membutuhkan pembelian, lalu dapat memangkas waktu commute dan perjalanan kota.
- Biaya bulanan sekarang terdiri dari rumah + gaya hidup + transportasi dan tetap mengikuti indeks biaya dunia.
- Perubahan gaya hidup/transportasi memiliki jeda agar pemain tidak bisa mengganti pilihan tepat sebelum tagihan hanya untuk mengeksploitasi sistem.
- Semua kontrol ditaruh di KAMU; tidak ada tab Keuangan baru.

## Save

Save version 28. SAVE_KEY lama tetap dipakai sehingga Build AE v27 bermigrasi otomatis tanpa reset.

## Deploy

Upload seluruh isi folder ke root GitHub Pages, termasuk `src/`, `styles/`, dan `assets/`. Setelah deploy, hard refresh atau tutup-buka PWA agar cache Build AF aktif.

Aplikasi tetap Rp0 app: tidak ada paywall, IAP, premium currency, loot box, atau fitur gameplay berbayar.
